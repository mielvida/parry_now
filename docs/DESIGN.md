# 2D 플랫포머 설계 문서

## 실행 방법
`index.html`을 브라우저에서 열면 된다 (서버·빌드 불필요).

| 입력 | 동작 |
|---|---|
| ← → / A D | 좌우 이동 |
| Space / ↑ / W / Z | 점프 (길게 누르면 높이 점프) |
| Enter | 패링 (0.3초간 판정, 성공하면 몹이 날아가 터짐) |
| Enter 길게 누르고 떼기 | 검 던지기 (게이지 절반 미만=1칸, 절반 넘으면 1칸부터 가득 4칸까지 비례) |
| - (빼기) | 슬라임 30마리를 맵 곳곳에 소환 (최대 300마리, 새 게임 시 정리) |
| Enter / Space (컷신 중) | 오프닝 건너뛰기 |
| R | 처음 위치로 이동 (목숨 소모 없음, 막혔을 때용) |
| Enter (게임오버 화면) | 다시 시작 |

## 파일 구조

```
parry_now/
├─ index.html          캔버스 + 스크립트 로드 (의존 순서대로)
├─ docs/DESIGN.md      이 문서
└─ src/
   ├─ config.js        상수 (타일 크기, 물리 수치) — 튜닝은 여기서만
   ├─ input.js         Input    : 키보드 → moveX / jumpHeld / jumpPressed
   ├─ terrain.js       Terrain  : 타일맵 + 충돌 질의 (solidTilesIn, isSolid)
   ├─ body.js          Body     : 위치/속도 + 지형 충돌 해결 (플레이어·몬스터 공용)
   ├─ monster.js       Monster  : 몬스터 공통(패링에 맞아 날아감 -> 폭발 -> 3초 뒤 부활)
   ├─ player.js        Player   : Body 상속, 키 입력 → 이동·점프
   ├─ slime.js         Slime    : Monster 상속, 순찰/추적/점프 AI
   ├─ bat.js           Bat      : Monster 상속, 날아다니는 몬스터 (순찰/추적/급강하)
   ├─ camera.js        Camera   : 플레이어 추적, 맵 경계 클램프
   ├─ cutscene.js      Cutscene : 오프닝 컷신(유리병 발견 -> 보물 지도 -> 출발)
   ├─ cave.js          Cave     : 동굴 테마(시차 배경·돌 타일·종유석·수정·비네트)
   ├─ hero.js          Hero     : 용사 그리기 + 20프레임 검 휘두르기 애니메이션
   ├─ sword.js         Sword    : 던진 검(부메랑) 이동·복귀
   ├─ effects.js       Effects  : 파티클·링·화면흔들림 (규칙과 무관한 연출)
   ├─ renderer.js      Renderer : 그리기 전담 (상태를 바꾸지 않음)
   ├─ levels.js        레벨 데이터 (ASCII 맵)
   └─ main.js          조립 + 고정 스텝 게임 루프
```

`file://`에서도 동작하도록 ES 모듈 대신 전역 네임스페이스 `window.Game`에 각 모듈을 등록한다.
나중에 번들러(Vite 등)를 도입하면 `import/export`로 그대로 옮길 수 있다.

## 모듈 책임과 의존 방향

```
main ─┬─> Input
      ├─> Terrain  <── levels (데이터)
      ├─> Player   ──> Terrain (충돌 질의), Input (읽기)
      ├─> Camera   ──> Terrain (경계)
      └─> Renderer ──> Terrain, Player, Camera (읽기 전용)
```

- **Player**는 그리는 법을 모르고, **Renderer**는 상태를 바꾸지 않는다.
- **Terrain**은 "이 영역과 겹치는 솔리드 타일이 무엇인가"만 답한다. 충돌 *해결*은 Player의 몫이다.
  → 이후 적·아이템 등 다른 엔티티도 같은 질의를 재사용할 수 있다.

## 핵심 규칙 구현

**게임 루프** — 고정 시간 스텝(1/60초) + 누적기. 모니터 주사율이 달라도 물리가 같다.

**충돌 처리** — 축 분리 AABB 충돌:
1. X축으로 이동 → 겹치는 타일이 있으면 이동 방향 기준으로 타일 옆면에 붙여 놓고 `vx = 0` (**벽 막힘**)
2. Y축으로 이동 → 낙하 중 겹치면 타일 위에 얹고 `onGround = true` (**땅 밟기**), 상승 중 겹치면 타일 아래에 붙이고 `vy = 0` (**천장 막힘**)

터널링 방지: 낙하 속도 상한(900px/s ≈ 프레임당 15px)이 타일 크기(32px)보다 작아 한 프레임에 타일을 건너뛰지 못한다.

**중력/점프** — 중력 1800px/s², 점프 초속 640px/s → 최대 높이 ≈ 114px(3.5타일). 아래는 조작감 보정용:
- *코요테 타임(0.1초)*: 발판을 막 벗어난 직후에도 점프 가능
- *점프 버퍼(0.1초)*: 착지 직전에 누른 점프를 기억
- *가변 점프*: 점프 키를 일찍 떼면 상승 중 중력 2배

**맵 경계** — 좌/우/위 바깥은 벽, 아래 바깥은 허공. 구덩이에 빠져 맵 아래로 벗어나면 리스폰한다.

## 슬라임 (몬스터)
- **같은 판정**: Player와 Slime은 `Body`를 상속해 동일한 `moveX/moveY` 충돌 코드를 쓴다.
- **순찰**: 시야 밖에서는 느리게 걷다가 벽·낭떠러지를 만나면 되돌아간다.
- **추적**: 플레이어가 시야(가로 6타일, 세로 3타일) 안에 들어오면 분홍색으로 변해 쫓아온다. 플레이어와 가로 2타일 이내이거나 벽에 막히면 점프한다. 구덩이(3타일 이상 낙차) 앞에서는 멈춘다.
- **점프**: 높이 약 38px(1타일). 1타일 턱은 오르고 2타일 벽은 못 넘는다. 점프 전 0.15초 웅크리고, 공중에서는 가로 속도가 절반으로 느려지며, 중력이 약해(`SLIME_GRAVITY_SCALE`) 둥실 떠오른다.
- **젤리 연출**: 웅크림/상승/착지/대기 상태에 따라 몸체가 눌리고 늘어난다. 이는 그림에만 적용되고 충돌 박스는 항상 동일하다.
- **구덩이 인식 제한**: 플레이어와의 사이에 구덩이(바닥 없는 열)가 있으면 시야 안이어도 알아채지 못하고 순찰한다.
- **용사/검 휘두르기**: 패링 버튼을 누르면 용사가 20프레임(`SWING_FRAMES`, 60Hz 기준 약 0.33초) 동안 검을 휘두른다. 0~4프레임 치켜들기 → 5~11프레임 빠르게 베기(검기 궤적 + 바람 이펙트) → 12~19프레임 복귀. 판정 시간(0.3초)은 이 애니메이션과 별개로 유지된다. 패링 성공 시 히트스톱으로 휘두르기 프레임도 같이 멈춘다.
- **검 던지기**: 패링 버튼을 0.3초(`SWORD_MIN_HOLD`) 넘게 누르고 있으면(처음 누른 순간은 평소처럼 패링) 충전 링이 차오르고, **손을 떼는 순간** 검이 날아간다. 날아가는 거리는 게이지 구간에 따라 달라진다. 절반(`SWORD_HALF_GAUGE`)에 못 미치면 1칸(`SWORD_SHORT_TILES`)으로 고정, 절반을 넘으면 1칸(`SWORD_MIN_TILES`)에서 시작해 채운 만큼 늘어나 1.5초(`SWORD_CHARGE_TIME`) 가득이면 4칸(`SWORD_THROW_TILES`)이다. 링의 절반 눈금을 넘으면 눈금이 밝아진다. 가득 차면 링이 금색으로 맥동하며 "준비 완료" 이펙트가 난다. 0.3초 미만으로 톡 누르면 던지지 않고 패링만 나가며, 쥐고 있는 동안은 던지지 않는다. **피격하면 게이지가 풀려**(깨지는 이펙트) 그 상태로 떼어도 던지지 않는다. 검은 던진 방향으로 날아간 뒤 돌아서서 **그때의 플레이어 손 위치**로 날아온다(던진 뒤 플레이어가 뒤돌아 달려도 나가는 방향은 그대로). 속도는 나갈 때 600px/s, 돌아올 때 700px/s로 플레이어(220px/s)보다 빠르다. 날아가는 동안 닿은 슬라임은 패링과 같이 튕겨나 터지고, 검이 손을 떠나 있는 동안엔 패링과 충전이 안 된다.
- **패링**: Enter를 누르면 0.3초간(`PARRY_WINDOW`) 플레이어 몸 주변 12px(`PARRY_REACH`) 판정이 열린다. 그 안에 슬라임이 닿으면 맞은 반대 방향으로 회전하며 날아가고(조종 불가·해롭지 않음), **벽·땅·천장에 닿는 순간** 터진다(2초 안에 아무것에도 안 닿거나 구덩이로 떨어져도 터짐). 연출: 충격파 링·불꽃·젤리 방울 파티클(`effects.js`), 화면 흔들림, 0.07초 히트스톱. 쿨다운 0.6초(헛스윙일 때만). **패링에 성공하면 쿨다운이 즉시 사라져** 줄지어 오는 슬라임을 바로 이어서 쳐낼 수 있고, 히트스톱 중에 누른 입력도 버려지지 않고 멈춤이 끝난 뒤 반영된다.
- **부활**: 터진 슬라임은 3초 뒤(`SLIME_RESPAWN_TIME`) 제자리에서 스폰 이펙트(링이 모이고 초록 빛이 솟음)와 함께 통통 커지며 부활한다. 나타나는 0.4초 동안은 해롭지 않다. 플레이어 리스폰(R/사망) 시에는 모두 즉시 원상복구.
- **패링 못 하고 플레이어와 접촉 시** 시작점으로 리스폰한다 (임시 규칙. 밟기/체력제는 미구현).
- 레벨의 `S` 문자가 슬라임 시작 위치.
- **대량 소환**: `-` 키를 누르면 `Terrain.standingSpots()`(빈 타일 + 바로 아래가 땅인 자리) 중 플레이어 시야 밖인 곳에 무작위로 30마리를 배치한다(`SLIME_SPAWN_BATCH`, 상한 `SLIME_MAX`). 화면 밖 슬라임은 그리지 않아 300마리까지 부드럽게 돈다.

## 박쥐 (날아다니는 몬스터)
- 슬라임과 같은 `Monster` 기반이라 충돌 판정·패링·던진 검·폭발·3초 뒤 부활이 똑같이 적용된다. 중력을 받지 않고 공중을 난다. 레벨의 `B` 문자가 시작 위치(5마리).
- **순찰**: 둥지 주변을 8자로 맴돈다. **추적**: 플레이어가 시야(가로 7타일, 세로 6타일) 안에 들어오면 머리 위 3타일 높이로 따라와 맴돈다(구덩이 건너편이어도 날아서 온다).
- **급강하**: 머리 위 약 1.75타일 이내에 오면 0.4초간 움츠리며(눈이 붉어짐) 노려본 뒤 플레이어 위치로 내리꽂는다(220px/s, 패링 타이밍을 읽을 수 있게 느리게). 벽·바닥에 부딪히거나 0.9초가 지나면 끝나고 1.6초 뒤 다시 노린다. **급강하를 보고 패링**하면 튕겨 나가 터진다.

## 오프닝 컷신과 보물
- **컷신**(`cutscene.js`): 게임을 처음 열면 약 16초 재생된다(`INTRO_CUTSCENE`로 끌 수 있음, Enter/Space로 건너뛰기). 영화 같은 위아래 띠와 자막이 나온다. ① 어둠 속에서 밝아지며 바닥의 반짝이는 유리병을 발견 ② 용사가 가상 입력으로 걸어가 병을 줍고 머리 위로 들어 올림 ③ 병 클로즈업: 코르크가 뽑히고 두루마리가 나옴 ④ 찢어진 양피지 위에 **실제 맵 축소판**과 출발점→보물까지 이어지는 빨간 점선 경로가 차례로 그려지고 X 표시 ⑤ 검을 휘두르며 "보물을 찾으러 가자!". 컷신 동안 몬스터는 멈춰 있고 게임 규칙(목숨 등)은 적용되지 않는다.
- **보물 상자**: 맵 끝 꼭대기 발판(레벨의 `T`)에 있고 닫혀 있을 땐 은은한 금빛을 낸다. 닿으면 뚜껑이 열리며 금화가 솟고 "보물을 찾았다!" 엔딩 후, Enter로 처음부터 다시 시작한다(컷신은 다시 재생하지 않음). 화면에는 "목표" 안내가 표시된다.

## 동굴 테마
- 배경: 어두운 남색~보라 그라데이션 위에 천장 종유석, 먼/가까운 능선, 석순, 맥동하는 푸른·보라·청록 수정을 층마다 다른 속도로 움직여(시차) 깊이감을 준다. 화면 가장자리는 어둡게(비네트), 아래쪽(구덩이)은 더 깊게 보이게 한다.
- 땅: 타일마다 명도가 조금씩 다른 돌에 결·균열·광물 알갱이를 넣고, 위가 열린 면은 젖은 돌 하이라이트와 이끼, 아래가 열린 면은 종유석을 그린다. 무늬는 좌표 해시로 정해져 프레임마다 똑같다. 맵 천장(y=0)에도 종유석이 매달려 있다.
- 어두운 배경에서 읽히도록 안내 글씨는 밝은색+그림자, 박쥐는 밝은 보라색+윤곽선으로 그린다.

## 목숨
- 시작 목숨 3개(`PLAYER_LIVES`). 패링하지 못하고 슬라임에 닿으면 목숨이 1개 줄고 **그 자리에 그대로** 남는다. 붉은 충격파·불꽃·붉은 번쩍·화면 흔들림 이펙트가 나오고, 1.5초간(`PLAYER_INVULN`) 깜빡이며 무적이다(겹쳐 있어도 연속으로 깎이지 않게).
- 구덩이에 빠지면 목숨이 줄고, 허공이라 "그 자리"가 없으므로 마지막으로 땅을 밟고 있던 위치에서 이어간다.
- 0이 되면 화면이 멈추고 GAME OVER 표시. 1초 뒤(`GAME_OVER_DELAY`, 연타로 건너뛰기 방지) "Enter 키로 다시 시작"이 나타나고, Enter를 누르면 목숨 3개로 처음부터 시작한다. 우측 상단 하트로 남은 목숨을 보여준다.

## 레벨 1 구성 (130×18 타일, 슬라임 7마리)
- 구간 1 (0~71열): 공중 발판 → 3칸 구덩이 → 기둥(옆면 막힘) → 낮은 천장(머리 부딪힘) → 3칸 구덩이 → 계단 → 높은 발판
- 구간 2 (72~129열): 계단식 공중 발판 → 3칸 구덩이 → 2칸 기둥 → 3칸 탑 → 4칸 구덩이 → 계단 → 꼭대기 발판
점프 사거리(수평 약 5타일, 높이 3.5타일) 안에서 모든 구간에 도달 가능하게 배치했다.

## 확장 지점
- 새 레벨: `levels.js`에 문자열 배열 추가 (`#` 땅, `P` 시작점)
- 새 타일 종류(가시, 한 방향 발판 등): `Terrain`의 `grid` 값을 불리언에서 타일 ID로 확장
- 적/아이템: `solidTilesIn`을 재사용하는 엔티티 클래스 추가, `main.step`에서 갱신, `Renderer`에서 그리기
