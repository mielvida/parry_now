# 2D 플랫포머 설계 문서

## 실행 방법
`index.html`을 브라우저에서 열면 된다 (서버·빌드 불필요).

| 입력 | 동작 |
|---|---|
| ← → / A D | 좌우 이동 |
| Space / ↑ / W / Z | 점프 (길게 누르면 높이 점프) |
| Enter | 패링 (0.3초간 판정, 성공하면 몹이 날아가 터짐) |
| Enter 길게 누르고 떼기 | 검 던지기 (게이지 절반 미만=1칸, 절반 넘으면 1칸부터 가득 4칸까지 비례) |
| - (빼기) | 슬라임 30마리를 맵 곳곳에 소환 (최대 300마리, 새 게임 시 정리) |
| Enter / Space (컷신 중) | 오프닝 건너뛰기 |
| R | 처음 위치로 이동 (목숨 소모 없음, 막혔을 때용) |
| Enter (게임오버 화면) | 다시 시작 |

## 파일 구조

```
parry_now/
├─ index.html          캔버스 + 스크립트 로드 (의존 순서대로)
├─ docs/DESIGN.md      이 문서
└─ src/
   ├─ config.js        상수 (타일 크기, 물리 수치) — 튜닝은 여기서만
   ├─ input.js         Input    : 키보드 → moveX / jumpHeld / jumpPressed
   ├─ terrain.js       Terrain  : 타일맵 + 충돌 질의 (solidTilesIn, isSolid)
   ├─ body.js          Body     : 위치/속도 + 지형 충돌 해결 (플레이어·몬스터 공용)
   ├─ monster.js       Monster  : 몬스터 공통(패링에 맞아 날아감 -> 폭발 -> 3초 뒤 부활)
   ├─ player.js        Player   : Body 상속, 키 입력 → 이동·점프
   ├─ slime.js         Slime    : Monster 상속, 순찰/추적/점프 AI
   ├─ bat.js           Bat      : Monster 상속, 날아다니는 몬스터 (순찰/추적/급강하)
   ├─ camera.js        Camera   : 플레이어 추적, 맵 경계 클램프
   ├─ forge.js         Forge    : 대장간(합치기·제련·부착·곡괭이), 광석 16종, 합성 단계 무기
   ├─ orecave.js       OreNodes : 광물 동굴의 광석 덩어리와 곡괭이질
   ├─ events.js        DungeonEvents : 던전 이벤트·층 변수 (함정, 상인, 샘, 혈월 …)
   ├─ cutscene.js      Cutscene : 오프닝 컷신(유리병 발견 -> 보물 지도 -> 출발)
   ├─ cave.js          Cave     : 동굴 테마(시차 배경·돌 타일·종유석·수정·비네트)
   ├─ hero.js          Hero     : 용사 그리기 + 20프레임 검 휘두르기 애니메이션
   ├─ sword.js         Sword    : 던진 검(부메랑) 이동·복귀
   ├─ effects.js       Effects  : 파티클·링·화면흔들림 (규칙과 무관한 연출)
   ├─ renderer.js      Renderer : 그리기 전담 (상태를 바꾸지 않음)
   ├─ levels.js        레벨 데이터 (ASCII 맵)
   └─ main.js          조립 + 고정 스텝 게임 루프
```

`file://`에서도 동작하도록 ES 모듈 대신 전역 네임스페이스 `window.Game`에 각 모듈을 등록한다.
나중에 번들러(Vite 등)를 도입하면 `import/export`로 그대로 옮길 수 있다.

## 모듈 책임과 의존 방향

```
main ─┬─> Input
      ├─> Terrain  <── levels (데이터)
      ├─> Player   ──> Terrain (충돌 질의), Input (읽기)
      ├─> Camera   ──> Terrain (경계)
      └─> Renderer ──> Terrain, Player, Camera (읽기 전용)
```

- **Player**는 그리는 법을 모르고, **Renderer**는 상태를 바꾸지 않는다.
- **Terrain**은 "이 영역과 겹치는 솔리드 타일이 무엇인가"만 답한다. 충돌 *해결*은 Player의 몫이다.
  → 이후 적·아이템 등 다른 엔티티도 같은 질의를 재사용할 수 있다.

## 핵심 규칙 구현

**게임 루프** — 고정 시간 스텝(1/60초) + 누적기. 모니터 주사율이 달라도 물리가 같다.

**충돌 처리** — 축 분리 AABB 충돌:
1. X축으로 이동 → 겹치는 타일이 있으면 이동 방향 기준으로 타일 옆면에 붙여 놓고 `vx = 0` (**벽 막힘**)
2. Y축으로 이동 → 낙하 중 겹치면 타일 위에 얹고 `onGround = true` (**땅 밟기**), 상승 중 겹치면 타일 아래에 붙이고 `vy = 0` (**천장 막힘**)

터널링 방지: 낙하 속도 상한(900px/s ≈ 프레임당 15px)이 타일 크기(32px)보다 작아 한 프레임에 타일을 건너뛰지 못한다.

**중력/점프** — 중력 1800px/s², 점프 초속 640px/s → 최대 높이 ≈ 114px(3.5타일). 아래는 조작감 보정용:
- *코요테 타임(0.1초)*: 발판을 막 벗어난 직후에도 점프 가능
- *점프 버퍼(0.1초)*: 착지 직전에 누른 점프를 기억
- *가변 점프*: 점프 키를 일찍 떼면 상승 중 중력 2배

**맵 경계** — 좌/우/위 바깥은 벽, 아래 바깥은 허공. 구덩이에 빠져 맵 아래로 벗어나면 리스폰한다.

## 슬라임 (몬스터)
- **같은 판정**: Player와 Slime은 `Body`를 상속해 동일한 `moveX/moveY` 충돌 코드를 쓴다.
- **순찰**: 시야 밖에서는 느리게 걷다가 벽·낭떠러지를 만나면 되돌아간다.
- **추적**: 플레이어가 시야(가로 6타일, 세로 3타일) 안에 들어오면 분홍색으로 변해 쫓아온다. 플레이어와 가로 2타일 이내이거나 벽에 막히면 점프한다. 구덩이(3타일 이상 낙차) 앞에서는 멈춘다.
- **점프**: 높이 약 38px(1타일). 1타일 턱은 오르고 2타일 벽은 못 넘는다. 점프 전 0.15초 웅크리고, 공중에서는 가로 속도가 절반으로 느려지며, 중력이 약해(`SLIME_GRAVITY_SCALE`) 둥실 떠오른다.
- **젤리 연출**: 웅크림/상승/착지/대기 상태에 따라 몸체가 눌리고 늘어난다. 이는 그림에만 적용되고 충돌 박스는 항상 동일하다.
- **구덩이 인식 제한**: 플레이어와의 사이에 구덩이(바닥 없는 열)가 있으면 시야 안이어도 알아채지 못하고 순찰한다.
- **용사/검 휘두르기**: 패링 버튼을 누르면 용사가 20프레임(`SWING_FRAMES`, 60Hz 기준 약 0.33초) 동안 검을 휘두른다. 0~4프레임 치켜들기 → 5~11프레임 빠르게 베기(검기 궤적 + 바람 이펙트) → 12~19프레임 복귀. 판정 시간(0.3초)은 이 애니메이션과 별개로 유지된다. 패링 성공 시 히트스톱으로 휘두르기 프레임도 같이 멈춘다.
- **검 던지기**: 패링 버튼을 0.3초(`SWORD_MIN_HOLD`) 넘게 누르고 있으면(처음 누른 순간은 평소처럼 패링) 충전 링이 차오르고, **손을 떼는 순간** 검이 날아간다. 날아가는 거리는 게이지 구간에 따라 달라진다. 절반(`SWORD_HALF_GAUGE`)에 못 미치면 1칸(`SWORD_SHORT_TILES`)으로 고정, 절반을 넘으면 1칸(`SWORD_MIN_TILES`)에서 시작해 채운 만큼 늘어나 1.5초(`SWORD_CHARGE_TIME`) 가득이면 4칸(`SWORD_THROW_TILES`)이다. 링의 절반 눈금을 넘으면 눈금이 밝아진다. 가득 차면 링이 금색으로 맥동하며 "준비 완료" 이펙트가 난다. 0.3초 미만으로 톡 누르면 던지지 않고 패링만 나가며, 쥐고 있는 동안은 던지지 않는다. **피격하면 게이지가 풀려**(깨지는 이펙트) 그 상태로 떼어도 던지지 않는다. 검은 던진 방향으로 날아간 뒤 돌아서서 **그때의 플레이어 손 위치**로 날아온다(던진 뒤 플레이어가 뒤돌아 달려도 나가는 방향은 그대로). 속도는 나갈 때 600px/s, 돌아올 때 700px/s로 플레이어(220px/s)보다 빠르다. 날아가는 동안 닿은 슬라임은 패링과 같이 튕겨나 터지고, 검이 손을 떠나 있는 동안엔 패링과 충전이 안 된다.
- **패링**: Enter를 누르면 0.3초간(`PARRY_WINDOW`) 플레이어 몸 주변 12px(`PARRY_REACH`) 판정이 열린다. 그 안에 슬라임이 닿으면 맞은 반대 방향으로 회전하며 날아가고(조종 불가·해롭지 않음), **벽·땅·천장에 닿는 순간** 터진다(2초 안에 아무것에도 안 닿거나 구덩이로 떨어져도 터짐). 연출: 충격파 링·불꽃·젤리 방울 파티클(`effects.js`), 화면 흔들림, 0.07초 히트스톱. 쿨다운 0.6초(헛스윙일 때만). **패링에 성공하면 쿨다운이 즉시 사라져** 줄지어 오는 슬라임을 바로 이어서 쳐낼 수 있고, 히트스톱 중에 누른 입력도 버려지지 않고 멈춤이 끝난 뒤 반영된다.
- **부활**: 터진 슬라임은 3초 뒤(`SLIME_RESPAWN_TIME`) 제자리에서 스폰 이펙트(링이 모이고 초록 빛이 솟음)와 함께 통통 커지며 부활한다. 나타나는 0.4초 동안은 해롭지 않다. 플레이어 리스폰(R/사망) 시에는 모두 즉시 원상복구.
- **패링 못 하고 플레이어와 접촉 시** 시작점으로 리스폰한다 (임시 규칙. 밟기/체력제는 미구현).
- 레벨의 `S` 문자가 슬라임 시작 위치.
- **대량 소환**: `-` 키를 누르면 `Terrain.standingSpots()`(빈 타일 + 바로 아래가 땅인 자리) 중 플레이어 시야 밖인 곳에 무작위로 30마리를 배치한다(`SLIME_SPAWN_BATCH`, 상한 `SLIME_MAX`). 화면 밖 슬라임은 그리지 않아 300마리까지 부드럽게 돈다.

## 박쥐 (날아다니는 몬스터)
- 슬라임과 같은 `Monster` 기반이라 충돌 판정·패링·던진 검·폭발·3초 뒤 부활이 똑같이 적용된다. 중력을 받지 않고 공중을 난다. 레벨의 `B` 문자가 시작 위치(5마리).
- **순찰**: 둥지 주변을 8자로 맴돈다. **추적**: 플레이어가 시야(가로 7타일, 세로 6타일) 안에 들어오면 머리 위 3타일 높이로 따라와 맴돈다(구덩이 건너편이어도 날아서 온다).
- **급강하**: 머리 위 약 1.75타일 이내에 오면 0.4초간 움츠리며(눈이 붉어짐) 노려본 뒤 플레이어 위치로 내리꽂는다(220px/s, 패링 타이밍을 읽을 수 있게 느리게). 벽·바닥에 부딪히거나 0.9초가 지나면 끝나고 1.6초 뒤 다시 노린다. **급강하를 보고 패링**하면 튕겨 나가 터진다.

## 오프닝 컷신과 보물
- **컷신**(`cutscene.js`): 게임을 처음 열면 약 16초 재생된다(`INTRO_CUTSCENE`로 끌 수 있음, Enter/Space로 건너뛰기). 영화 같은 위아래 띠와 자막이 나온다. ① 어둠 속에서 밝아지며 바닥의 반짝이는 유리병을 발견 ② 용사가 가상 입력으로 걸어가 병을 줍고 머리 위로 들어 올림 ③ 병 클로즈업: 코르크가 뽑히고 두루마리가 나옴 ④ 찢어진 양피지 위에 **실제 맵 축소판**과 출발점→보물까지 이어지는 빨간 점선 경로가 차례로 그려지고 X 표시 ⑤ 검을 휘두르며 "보물을 찾으러 가자!". 컷신 동안 몬스터는 멈춰 있고 게임 규칙(목숨 등)은 적용되지 않는다.
- **보물 상자**: 맵 끝 꼭대기 발판(레벨의 `T`)에 있고 닫혀 있을 땐 은은한 금빛을 낸다. 닿으면 뚜껑이 열리며 금화가 솟고 "보물을 찾았다!" 엔딩 후, Enter로 처음부터 다시 시작한다(컷신은 다시 재생하지 않음). 화면에는 "목표" 안내가 표시된다.

## 동굴 테마
- 배경: 어두운 남색~보라 그라데이션 위에 천장 종유석, 먼/가까운 능선, 석순, 맥동하는 푸른·보라·청록 수정을 층마다 다른 속도로 움직여(시차) 깊이감을 준다. 화면 가장자리는 어둡게(비네트), 아래쪽(구덩이)은 더 깊게 보이게 한다.
- 땅: 타일마다 명도가 조금씩 다른 돌에 결·균열·광물 알갱이를 넣고, 위가 열린 면은 젖은 돌 하이라이트와 이끼, 아래가 열린 면은 종유석을 그린다. 무늬는 좌표 해시로 정해져 프레임마다 똑같다. 맵 천장(y=0)에도 종유석이 매달려 있다.
- 어두운 배경에서 읽히도록 안내 글씨는 밝은색+그림자, 박쥐는 밝은 보라색+윤곽선으로 그린다.

## 목숨
- 시작 목숨 3개(`PLAYER_LIVES`). 패링하지 못하고 슬라임에 닿으면 목숨이 1개 줄고 **그 자리에 그대로** 남는다. 붉은 충격파·불꽃·붉은 번쩍·화면 흔들림 이펙트가 나오고, 1.5초간(`PLAYER_INVULN`) 깜빡이며 무적이다(겹쳐 있어도 연속으로 깎이지 않게).
- 구덩이에 빠지면 목숨이 줄고, 허공이라 "그 자리"가 없으므로 마지막으로 땅을 밟고 있던 위치에서 이어간다.
- 0이 되면 화면이 멈추고 GAME OVER 표시. 1초 뒤(`GAME_OVER_DELAY`, 연타로 건너뛰기 방지) "Enter 키로 다시 시작"이 나타나고, Enter를 누르면 목숨 3개로 처음부터 시작한다. 우측 상단 하트로 남은 목숨을 보여준다.

## 레벨 1 구성 (130×18 타일, 슬라임 7마리)
- 구간 1 (0~71열): 공중 발판 → 3칸 구덩이 → 기둥(옆면 막힘) → 낮은 천장(머리 부딪힘) → 3칸 구덩이 → 계단 → 높은 발판
- 구간 2 (72~129열): 계단식 공중 발판 → 3칸 구덩이 → 2칸 기둥 → 3칸 탑 → 4칸 구덩이 → 계단 → 꼭대기 발판
점프 사거리(수평 약 5타일, 높이 3.5타일) 안에서 모든 구간에 도달 가능하게 배치했다.

## 던전 이벤트 (`events.js`)
다크월드 어둠의 탑의 **3층마다**(3, 6, 9 … 단 보스 층 33/66 제외) 이벤트가 무작위로 깔린다. 그 층에는 5~12개가 나오고, 서 있을 수 있는 발판 위에만, 시작점·문 근처를 피해 서로 겹치지 않게 놓인다. 이벤트는 게임 규칙을 직접 건드리지 않고 `main.js`가 넘겨주는 `host`(heal/hurt/coins/exp/spawnMonster …)로만 요청한다.

**상호작용형 (E 키, 가까이 가면 안내가 뜬다)**
- 회복의 샘(피 +1, 가득이면 소모 안 함) · 떠돌이 상인(E로 값을 묻고 한 번 더 E로 구매, 2종) · 저주받은 제단(55% 축복 / 45% 하수인 매복) · 수상한 상자(60% 보상 / 40% 미믹) · 소원의 우물(25G, 3번) · 수호의 룬(10초 무적+스태미나 가득) · 보급 상자(소모품+코인) · 방랑 기사(힌트 대사, 처음엔 EXP)

**함정·구역형 (닿거나 베면 발동)**
- 가시 함정(숨음→경고→솟음 주기) · 낙석 발판(밟으면 경고 그림자 후 바위 4개) · 화염 분출구(진동→불기둥) · 매복 표식(밟으면 몬스터, 모두 물리치면 보상) · 폭발 통(베면 폭발, 연쇄, 몬스터를 날리지만 곁에 서 있으면 플레이어도 다친다) · 돌풍 통로(방향이 바뀐다)
- 함정 피해는 `1 + 층/30` 하트. 맞으면 보통 피격처럼 무적 시간이 생긴다.

**보너스·이동형**
- 황금 도둑 요정(도망치다 막다른 곳에서 순간이동, 잡거나 베면 큰돈, 20초 뒤 사라짐) · 코인 아치(7개를 모으면 보너스, 지형에 박힌 아치는 배치하지 않음) · 도약 버섯(위에서 밟으면 약 6타일 높이 점프) · 차원문 한 쌍(낮은 발판 ↔ 4칸 이상 높은 발판 지름길)

**층 전체 변수 (2층부터 약 40% 확률로 한 층에 하나)**
- 혈월(몬스터 속도 ×1.35, 보상 ×2, 8층~) · 황금 비(하늘에서 코인이 쏟아짐) · 짙은 안개(시야 축소, 보상 ×1.5, 5층~) · 지진(주기적으로 바위, 보상 ×1.5, 4층~) · 별빛의 축복(피가 천천히 참)
- 보상 배율은 몬스터 처치 보상(코인·EXP)에 `main.js`가 곱한다 (`rewardMul()`).

**임시 몬스터**: 이벤트가 불러낸 몬스터(`temp`)는 층에 맞게 단단해지고 처치 보상도 주지만, 죽으면 부활하지 않고 정리된다.

## 시작 장비와 대장간 (`forge.js`)
- **시작 장비**: 허름한 옷(기운 천 조각 옷, 최대 피 +0)과 부서진 목검(끝이 뜯겨 나간 나무 칼)으로 시작한다. 기본 검(80G)은 대장간에서 산다.
- **같은 무기 여러 자루**: 대장간(마을 `W`, 무기 가게 겸)에서 같은 무기를 또 사면 한 자루 더 가진다(인벤토리에 `x3`처럼 보인다).
- **합치기 작업대**(용광로의 첫 탭): 3칸에 **같은 무기 3개**를 올리면 한 단계 위 1개가 된다(1단계 "강화된 …", 2단계 "최강의 …"=최대). 단계가 오를수록 모습(은은한 빛 → 반짝이는 불꽃과 날밑 보석)과 공격이 강해진다.
  - **1분**이 걸린다. **직접**(무료)은 용광로 곁(7칸 이내)에 있는 동안만 시간이 가고, **대장장이 아저씨에게 맡기면**(70G) 어디에 있든 1분 뒤 완성되니 그동안 다른 일을 할 수 있다. 작업은 한 번에 하나. 화면 오른쪽 위에 남은 시간이 뜨고, 끝나면 용광로에서 **찾는다**.
  - 근접: 기본 대미지 ×4 / ×10, 범위 +15% / +30%, 던지기 거리 +1·+2칸, 1단계부터 슬라임·꽃게 한 방. 쏘는 무기: 대미지 ×2.8 / ×5.5, 스태미나 절감, 폭탄 폭발 범위 증가, 최대 단계의 총·활은 관통.
  - 재료 3개는 맡기는 순간 작업대로 넘어간다(그동안 든 무기였다면 목검을 든다). 강화 레벨·신성·붙인 주괴는 완성품이 이어받는다. 모든 무기(목검·돋보기 제외)에 1·2단계가 미리 만들어져 있다.
- **대장간 탭**(무기 상점): 검 · 대검 · 단검 · 지팡이 · **곡괭이**.
- **용광로 탭**(대장간 오른쪽, 마을 `f`): **합치기** · **제련** · **부착** · **신성 강화**. 한 화면에 4개씩 보이고 ↑↓/PageUp·PageDown/휠/버튼으로 페이지를 넘긴다(모든 상점 공통).
- **제련**: 광석 3개 → 주괴 1개(수수료 `20×광석 단계` G). 광석을 고르면 **온도 맞추기 미니게임**(제한 100초)이 열린다 — Space/Enter/마우스를 누르면 풀무질로 온도가 오르고 떼면 식으며, 온도 눈금이 초록 띠(알맞은 온도)에 머무는 동안 녹는다. 너무 차가우면 조금씩, 너무 뜨거우면 빠르게 굳는다. **광석이 희귀할수록 어렵다**: 4단계는 최대 난이도(띠가 좁고 크게 움직이며, 온도가 빨리 식고 불길이 거세고, 굳는 벌이 크고, 8→20초를 버텨야 한다)이고 1단계는 아주 쉽다(넓고 느린 띠, 천천히 식고, 벌이 작고, 약 8초면 된다). 시간 초과·Esc 포기는 실패(광석과 수수료 그대로), 성공할 때만 광석 3개와 수수료를 쓴다. **부착**: 지금 든 무기에 주괴를 붙인다. 주괴를 고르면 **두드려 붙이기 미니게임**(제한 시간 2분)이 열린다 — 움직이는 눈금이 초록 칸에 있을 때 Space/Enter/클릭으로 망치질(완벽 +10, 좋음 +5, 빗나감 -10), 진행 100%면 붙는다. **광석이 희귀할수록 어렵다**: 4단계(별철·심연석·백금·암흑강)는 어렵지만 읽을 만하다(초록 칸 ±9%·완벽 ±3.2%, 눈금 약 3.2 rad/s에 살짝 들쭉날쭉, 진행이 초당 0.4 식고 칸이 조금 흔들림, 완벽 +12·좋음 +6·빗나감 -8). 1단계(철·구리·초석·납)는 쉽다(초록 칸 ±18%·완벽 ±7%, 눈금 약 2 rad/s, 완벽 +15·좋음 +9·빗나감 -3, 식거나 흔들리지 않음). 시간 초과·Esc 포기는 실패이며 주괴와 수수료는 그대로, 성공할 때만 수수료를 낸다(칸: 무기는 1레벨 1칸 → 합쳐서 2레벨 3칸 → 3레벨(최대) 5칸, 방어구는 값어치에 따라 1/3/5칸. 수수료 `40×단계` G). 검(근접)용 주괴와 총(쏘는 무기)용 주괴가 따로 있어 맞지 않는 쪽엔 못 붙인다. 떼어내면 주괴는 사라진다.
- **광석 35종**(갑옷용 12 / 검용 15: 철·구리·은·금·미스릴·흑요석·별철·심연석 / 총용 8: 초석·납·황철석·유황·티타늄·폭렬석·백금·암흑강). 주괴 효과: 대미지·보스 대미지·범위·쿨다운·치명타·코인·단단한 몬스터 깎는 횟수(검), 탄환 대미지·스태미나 절감·폭발 범위·관통(총).
- **용광로는 대상을 먼저 고른다**: 용광로에서 E를 누르면 **1 검 / 2 투척 무기(총·활·폭탄 등) / 3 갑옷** 중 종류를 고르고, 그 종류로 **가진 것을 모두 보여 준** 뒤 강화할 것 하나를 고른다(방향키·휠·클릭, Backspace로 뒤로). 그러면 그 아이템을 대상으로 용광로가 열려 **합치기(무기만, 대상 하나) · 제련(그 종류의 광석) · 부착 · 신성 강화(검만) · 크리스탈** 탭이 나온다. 끼고 있지 않은 것도 강화할 수 있고, 용광로 창에서 Backspace로 대상을 바꾼다.
- **갑옷 광석**(12종, 방어구 어디에든 붙인다): 철갑석·날쌘석(1단계), 수호석·가시석(2단계), 용린석·화린석·냉린석·독린석·탐욕석(3단계), 뇌린석·생명석·거인석(4단계). 모두 **최대 피 +1칸 이상**이고, 무적 시간 +0.15~0.5초, 이동 속도, 코인 보너스를 주며, 가시·화염·얼음·독가시·탐욕·번개·재생 **속성 능력**을 붙이는 광석도 있다.
- **속성은 많을수록 강해진다**: 입은 방어구 5곳에 붙은 같은 속성(갑옷 자체 속성 포함)이 하나 늘 때마다 화염·독가시·얼음·번개의 범위가 +25%, 재생은 더 자주(10초 → 최소 3초), 탐욕은 +15%씩 더 붙는다. 무기의 원소 광석도 같은 속성이 하나 늘 때마다 효과 범위 +35%.
- **원소 광석**(검용): 화염석(불)·서리석(얼음)·독석(독)·대지석(대지)은 3단계, 번개석(번개·빛)·그림자석(그림자)은 4단계. 주괴를 붙이면 **그 속성이 무기에 같이 적용된다** — 무기 자체 속성(황금·수정 등)에 더해져 맞힐 때 모두 일어나고(불에 타고 독에 중독되는 식), 보스의 약점 속성과 맞으면 약점 대미지(×3)도 받는다. 같은 속성은 한 번만 센다.
- **균열석**(검용, 3단계): 붙이면 **균열을 무시**한다 — 다크월드의 단단한 몬스터(여러 번 때려 금이 가야 쓰러지는 것)도 금이 가는 단계 없이 한 방에 쓰러뜨린다.
- **대장장이는 마을에 한 명뿐**이다. 용광로 옆에 서 있고(발이 땅에 닿는다), 대장간과 특수 무기 가게의 주인은 다른 사람이다.
- **광석이 희귀할수록 효과가 엄청나게 세다**(주괴 하나당): 1단계 대미지 **+2**(총은 탄환 +2, 가장 흔한 광석도 최소 +2) → 2단계 +3~4(총 +2~3) → 3단계 +12~16(보스 +16, 총 +8~10) → 4단계 **+30~40**(심연석은 보스 +60, 총 +25~30). 칸이 최대 5개라 4단계 주괴 5개면 대미지가 수백 단위가 된다.
- **대장 숙련도(Lv 1~10)**: 합치기 완성품 찾기·제련·부착·크리스탈 합치기를 직접 할 때마다 경험치(제련 5×단계, 부착 8×단계, 합치기 12×(단계+1), 크리스탈 15)가 쌓여 레벨이 오른다. 레벨이 오를수록 미니게임이 쉬워진다(최고 레벨: 초록 칸/띠 +50%, 눈금 -25%, 식는 속도·흔들림·벌 감소). 용광로 창 머리말과 미니게임 위쪽에 레벨과 경험치 막대가 보인다.
- **대장장이에게 맡기기**: 제련/부착 광석을 고르면 먼저 "직접 하기(미니게임, 경험치 획득)"와 "대장장이에게 맡기기(확실히 성공, 경험치 없음)" 중에 고른다. 맡김 수수료는 재료 수수료와 별도이고 광석이 희귀할수록 훨씬 비싸다(제련 60/200/700/2,500 G, 부착 100/350/1,200/4,000 G). 합치기는 위의 70G 맡기기를 쓴다.
- **크리스탈 합치기**(용광로의 `크리스탈` 탭): 어둠의 크리스탈 3개 → 정화된 크리스탈 1개(300 G), 정화된 크리스탈 3개 → 신성 크리스탈 1개(800 G). 숲의 샘물·화산의 제단을 돌지 않아도 되는 대신 비싸다.
- **대장장이 아저씨 표지**: 용광로 옆과 대장간의 대장장이 머리 위에 "⚒ 대장장이" 표지가 둥실 떠 있고, 맡긴 합치기가 끝나면 "완성!"으로 바뀐다.
- **곡괭이** 4종(나무 150G · 철 700G · 강철 2,000G · 미스릴 5,000G): 가진 것 중 가장 좋은 단계가 자동으로 쓰인다.

## 광물 동굴 (`orecave.js`)
- 마을 39열의 **광물 동굴 문**으로 들어간다(개발 메뉴에서도 이동 가능). 들어갈 때마다 새로 생성되고 탐험 횟수가 늘수록 길어진다. 끝의 상자는 코인을 준다(마을 동굴의 60%).
- 바닥과 발판에 광석 덩어리(노드)가 놓여 있다. 가까이 가서 **E를 누르거나 길게 누르면** 곡괭이를 휘둘러 판다(진행 막대). 곡괭이 단계가 광석 단계보다 낮으면 캘 수 없고(안내 문구가 뜬다), 단계가 높을수록 한 번에 더 깊이 판다(1단계 6번 → 4단계 광석을 최고 곡괭이로 3번).
- 동굴 안쪽(오른쪽)일수록, 탐험 횟수가 많을수록 높은 단계(희귀한) 광석이 나온다. 캐면 1~3개가 인벤토리 '재료'에 쌓인다.

## 인벤토리 (I 키)
- **I** 키(또는 `]`)로 어느 스테이지에서든 열고 닫는다.
- **★ 최고 장착 (H)**: 방어구 5칸(갑옷·투구·장갑·바지·신발)을 가진 것 중 가장 좋은 것(`powerOf` 점수)으로 한 번에 맞춘다. 무기는 건드리지 않는다.

## 결투장 무기 규칙
- **던지는 무기** = 던지거나 쏘는 무기(폭탄·총·산탄총·활·석궁). **총싸움**은 반드시 장착해야 시작할 수 있고, **공격!**(칼싸움)은 장착하고 있으면 시작할 수 없다. 결투 중에도 규칙을 어기는 무기로 바꿀 수 없다(결투장 안에서만 적용).

- 이동 항목은 **지역 이름 아래에 그 지역의 실제 게임 화면 사진**이 붙은 카드다(`assets/regions/<이름>.png`, 35장: 스테이지 18곳, 마을 가게 9곳(용광로 포함), 다크월드 가게 4곳, 놀이마당 4곳). 사진은 게임을 구동해 16:9로 찍은 것이다.
